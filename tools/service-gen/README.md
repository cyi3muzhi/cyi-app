# Service Generator

服务生成器是一个用于快速生成 Kratos 微服务的工具，可以根据模板生成完整的服务代码结构。

## 功能特性

- ✅ 支持自定义服务名称
- ✅ 自动生成完整的目录结构
- ✅ 包含 gRPC 服务实现
- ✅ 集成 Redis 和 MySQL 支持
- ✅ 自动生成配置文件
- ✅ 自动生成 API 层 proto 文件
- ✅ 可扩展的模板系统

## 目录结构

```
tools/service-gen/
├── main.go              # 生成器主程序
├── README.md            # 本文档
└── templates/           # 模板文件
    ├── cmd/service/     # 命令行入口模板
    ├── configs/         # 配置文件模板
    ├── internal/biz/    # 业务逻辑模板
    ├── internal/conf/   # 配置定义模板
    ├── internal/data/   # 数据层模板
    ├── internal/server/  # 服务器模板
    └── internal/service/ # 服务层模板
```

## 快速开始

### 1. 编译生成器

```bash
# 进入生成器目录
cd tools/service-gen

# 编译生成器
go build -o service-gen main.go
```

### 2. 生成服务

```bash
# 基本用法
./service-gen <service-name>

# 示例：生成一个名为 product 的服务
./service-gen product

# 带选项的用法
./service-gen product --description="Product service" --version="v1" --author="Your Name" --features="grpc,redis,mysql"
```

### 3. 生成的服务结构

生成的服务会创建在 `app/service/<service-name>` 目录下，包含以下结构（与现有产品服务完全一致）：

```
app/service/<service-name>/
├── cmd/
│   └── <service-name>/      # 命令行入口
│       ├── main.go          # 主程序
│       ├── wire.go          # 依赖注入配置
│       └── wire_gen.go      # 自动生成的依赖注入代码
├── configs/
│   ├── config.yaml          # 服务配置文件
│   └── register.yaml        # 服务注册配置
├── internal/
│   ├── biz/                 # 业务逻辑层
│   │   ├── biz.go           # 业务逻辑配置
│   │   └── <service-name>.go # 业务逻辑实现
│   ├── conf/                # 配置定义
│   │   ├── conf.pb.go       # 自动生成的配置代码
│   │   └── conf.proto       # 配置 proto 定义
│   ├── data/                # 数据访问层
│   │   ├── models/          # 数据模型
│   │   │   └── <service-name>.go # 数据模型定义
│   │   ├── data.go          # 数据层配置
│   │   └── <service-name>.go # 数据访问实现
│   ├── server/              # 服务器配置
│   │   ├── grpc.go          # gRPC 服务器配置
│   │   └── server.go        # 服务器配置
│   └── service/             # 服务层
│       ├── service.go        # 服务层配置
│       └── <service-name>.go # 服务实现
```

同时，会在 `api/service/<service-name>/v1/` 目录下生成对应的 proto 文件：

```
api/service/<service-name>/v1/
└── <service-name>.proto     # 服务 proto 定义
```

## 选项说明

| 选项 | 描述 | 默认值 |
|------|------|--------|
| `--description` | 服务描述 | `<service-name> service` |
| `--version` | 服务版本 | `v1` |
| `--author` | 作者名称 | `Generated by service-gen` |
| `--features` | 功能特性（逗号分隔） | `grpc,redis,mysql` |

## 支持的特性

| 特性 | 描述 |
|------|------|
| `grpc` | 启用 gRPC 服务 |
| `http` | 启用 HTTP 服务 |
| `redis` | 集成 Redis 支持 |
| `mysql` | 集成 MySQL 支持 |

## 后续步骤

生成服务后，您需要：

1. **安装依赖**：运行 `go mod tidy` 安装依赖
2. **实现业务逻辑**：根据您的业务需求实现具体逻辑
3. **配置数据库**：修改 `configs/config.yaml` 中的数据库配置
4. **构建和运行**：运行相应命令构建并运行服务

## 示例

### 生成产品服务

```bash
# 生成产品服务
./service-gen product

# 进入服务目录
cd ../../app/service/product

# 安装依赖
go mod tidy

# 构建服务
go build -o product cmd/product/main.go

# 运行服务
./product
```

### 生成用户服务

```bash
# 生成用户服务
./service-gen user --description="User management service" --author="Admin"

# 进入服务目录
cd ../../app/service/user

# 安装依赖
go mod tidy

# 构建和运行
go build -o user cmd/user/main.go
./user
```

## 自定义模板

如果您需要自定义生成的代码结构，可以修改 `templates` 目录下的模板文件。模板使用 Go 的 `text/template` 语法，可以使用以下变量：

- `{{.ServiceName}}` - 服务名称（原始输入）
- `{{.ServiceNameLower}}` - 服务名称（小写）
- `{{.ServiceNameUpper}}` - 服务名称（大写）
- `{{.ServiceNameTitle}}` - 服务名称（首字母大写）
- `{{.Description}}` - 服务描述
- `{{.Version}}` - 服务版本
- `{{.Author}}` - 作者名称
- `{{.Features}}` - 功能特性列表

## 注意事项

1. **服务名称**：建议使用单个单词，如 `user`、`product`、`order` 等
2. **依赖管理**：生成服务后需要运行 `go mod tidy` 安装依赖
3. **配置修改**：根据实际环境修改 `configs/config.yaml` 中的配置
4. **数据库**：确保 MySQL 和 Redis 服务已启动并可访问

## 故障排除

### 常见问题

1. **生成失败**：检查模板文件是否存在，目录权限是否正确
2. **依赖错误**：运行 `go mod tidy` 解决依赖问题
3. **编译错误**：检查 proto 文件是否正确
4. **运行错误**：检查配置文件中的数据库连接信息是否正确
