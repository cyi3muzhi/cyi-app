# 悦选商城 - 知识库文档

## 一、商城简介

悦选商城是一家专注于为用户提供优质商品和服务的在线购物平台。我们致力于为每一位用户提供便捷、安全、愉快的购物体验。

## 二、配送政策

### 2.1 发货时间
- 工作日下单：24小时内发货
- 周末/节假日下单：下一个工作日发货
- 定制商品：付款后3-5个工作日发货

### 2.2 运费说明
- 订单金额满99元：免运费
- 订单金额不足99元：收取8元基础运费
- 偏远地区（新疆、西藏、青海等）：额外收取15元偏远地区附加费
- 海外配送：暂不支持

### 2.3 配送范围
- 国内大部分城市支持配送
- 部分农村地区可能无法送达，下单前请确认
- 支持配送至中国大陆所有省份和直辖市

## 三、退换货政策

### 3.1 七天无理由退换
- 自收到商品之日起7天内，支持无理由退换货
- 商品需保持完好状态，不影响二次销售
- 退换货产生的运费由买家承担
- 定制商品不支持七天无理由退换

### 3.2 商品质量问题
- 收到商品如有质量问题，请在48小时内联系客服
- 质量问题的退换货运费由悦选商城承担
- 需要提供商品问题的照片或视频证据

### 3.3 退换货流程
1. 联系在线客服或拨打客服电话400-888-8888
2. 说明退换货原因，提供订单号
3. 客服审核通过后，会发送退换货地址
4. 按要求将商品寄回
5. 收到商品后3个工作日内处理退款或换货

### 3.4 不予退换的情况
- 超过七天无理由退换期限
- 商品已被使用、损坏或丢失配件
- 定制商品（非质量问题）
- 特殊标注"不支持退换"的商品

## 五、优惠券使用规则

### 5.1 优惠券类型

- 满减优惠券：满199减20、满399减50等
- 品类优惠券：指定商品或品类可用
- 限时优惠券：有效期内使用

- 每笔订单只能使用一张优惠券
- 优惠券不可叠加使用
- 优惠券不能兑换现金
- 优惠券有效期以具体券面说明为准
- 订单取消后优惠券不退回

### 5.3 获取方式
- 新用户注册自动发放
- 参加平台活动获取
- 关注公众号获取专属优惠券
- 老用户回馈不定期发放
