### 跨境电商 POD 服务平台开发（Go）

项目描述：基于 Kratos 微服务框架构建的跨境电商按需打印（POD）服务平台，对接 SHEIN、Shopee、Temu 等多平台，实现订单同步、物流发货、面单打印全链路闭环。

主要职责：

- **SHEIN 半托管平台对接**：独立封装 SHEIN 开放平台 API 客户端，实现签名认证与 AES 加解密，完成订单查询、在线下单、物流渠道管理、批量上传运单号等全流程对接
- **分布式限流组件**：基于 Redis 有序集合实现滑动窗口分布式限流器，配合指数退避重试，保障高并发下第三方接口调用的稳定性
- **Shopee / 订单核心系统**：对接 Shopee 订单同步与批量发货，参与多平台订单统一管理，支持批量面单打印、Excel 导出、支付跟踪

技术栈：Go / Kratos / gRPC / Protobuf / MySQL / Redis / GORM / Consul / Jaeger / Docker / 阿里云 OSS/ECI

### x-pod 供应链接台 — 后端核心开发者（Go）

2025.01 - 至今

项目描述：面向跨境电商的供应链接台，涵盖商户管理、工厂管理、产品管理、订单管理、设计素材管理、AI 图像处理等核心业务模块。

主要职责与成果：

- **设计素材系统迁移重构**：主导从旧系统到新架构的完整迁移，重构图库管理、分类系统、附件上传等核心功能
- **AI 图像处理集成**：对接阿里云 FC 实现品牌设计师、图片转 SVG、背景透明化、图像分析等多个 AI 功能，设计异步提交+同步查询+重试的健壮机制
- **多工艺风格化资源**：实现雕刻、刺绣、提花、印刷等多种 AI 风格化工艺的资源管理与动态配置
- **工厂管理体系**：从零构建工厂 CRUD、排名、客户管理、需求管理、生产线配置、产能计算等完整功能链路
- **产品与订单系统**：实现 SPU 管理、工艺规格、商品模板导入导出、工厂认领等功能，修复多个生产环境问题

技术栈：Go / Kratos / gRPC / Protobuf / MySQL / Redis / GORM / Consul / Jaeger / Docker / 阿里云 OSS/ECI/FC / WebSocket

### 多租户电商 SaaS 平台 — 后端核心开发者（Go）

项目描述：基于 Kratos v2 微服务架构的多租户电商平台，支持商城端、商户端、平台端三端分离，涵盖商品、订单、支付、客服等全链路电商能力。

主要职责与成果：

- **订单交易系统**：负责订单全生命周期管理，实现代付、赠礼等社交化交易，以及优惠券分摊、阶梯价计算等复杂业务逻辑，处理支付回调、退款对账等资金敏感操作
- **商品管理体系建设**：主导 SPU/SKU 管理、分类、赠品、工艺属性等模块开发，实现商品搜索、排序置顶、拉黑过滤、子店铺批量认领等运营能力
- **分享服务与社交裂变**：设计设计类分享功能，支持扩展信息解析、版本管理、点击追踪，打通购物车与分享链路
- **客服会话系统**：从零搭建智能客服与人工客服系统，支持多店铺绑定、会话分配、消息缓存、超时自动转换
- **基础设施与工具链**：开发 Trace ID 注入中间件实现链路追踪，编写 ORM 代码生成器自动化生成分层代码，实现基于 MQ 的商品推送与异步任务

技术栈：Go / Kratos / gRPC / Protobuf / MySQL / Redis / GORM / Consul / Jaeger / Docker / 阿里云 OSS
