## 第一章：项目启动与基础概念

### 1.1 环境准备

在开始之前，确保你的电脑已经安装了：
- **Node.js**（版本 18+）：运行 JavaScript 的环境
- **pnpm**：包管理器（项目使用 pnpm，比 npm 更快）
- **VS Code**：代码编辑器（推荐）

检查安装是否成功：

```bash
node -v    # 显示 Node.js 版本，如 v20.11.0
pnpm -v    # 显示 pnpm 版本，如 9.12.3
```

### 1.2 启动项目

打开终端，进入项目目录：

```bash
cd e:\me\cyi-app\web\admin
```

安装依赖（第一次需要安装，以后不需要）：

```bash
pnpm install
```

启动开发服务器：

```bash
pnpm run dev
```

打开浏览器访问 `http://localhost:3000`，你应该能看到登录页面。

### 1.3 项目结构速览


## 第二章：Vue 3 核心语法

### 2.1 组件基本结构

每个 `.vue` 文件包含三个部分：

```vue
<template>
  <!-- HTML 结构（页面展示内容） -->
  <div class="hello">
    <h1>{{ message }}</h1>
    <button @click="changeMessage">点击修改</button>
  </div>
</template>

<script setup>
// JavaScript 逻辑（数据、方法）
import { ref } from 'vue'

// 响应式变量（数据变化自动更新视图）
const message = ref('Hello Vue!')

// 方法（点击按钮时执行）
function changeMessage() {
  message.value = 'Hello World!'
}
</script>

<style scoped>
/* CSS 样式（scoped 表示只作用于当前组件，不影响其他组件） */
.hello {
  text-align: center;
}
</style>
```

### 2.2 响应式基础

#### ref - 简单响应式

用于基本类型（字符串、数字、布尔值）：

```javascript
import { ref } from 'vue'

const count = ref(0)      // 数字
const name = ref('张三')  // 字符串
const isLogin = ref(false) // 布尔值

// 读取值（必须用 .value）
console.log(count.value)  // 输出：0

// 修改值（必须用 .value）
count.value++             // count 变为 1
name.value = '李四'       // name 变为 '李四'
```

#### reactive - 对象响应式

用于复杂类型（对象、数组）：

```javascript
import { reactive } from 'vue'

const form = reactive({
  username: '',
  password: ''
})

// 读取值（直接访问，不需要 .value）
console.log(form.username)

// 修改值（直接修改，不需要 .value）
form.username = 'admin'
form.password = '123456'
```

#### computed - 计算属性

根据其他值计算得出，自动缓存（依赖不变时不会重复计算）：

```javascript
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 计算全名
const fullName = computed(() => {
  return firstName.value + lastName.value
})

// 使用（和普通变量一样）
console.log(fullName.value)  // 输出：张三

// 当 firstName 或 lastName 变化时，fullName 会自动更新
firstName.value = '李'
console.log(fullName.value)  // 输出：李三
```

### 2.3 模板语法

#### 文本插值

```html
<!-- 显示变量 -->
<span>{{ message }}</span>

<!-- 显示表达式 -->
<span>{{ count * 2 }}</span>          <!-- 计算：count 的两倍 -->
<span>{{ isLogin ? '已登录' : '未登录' }}</span>  <!-- 条件判断 -->
<span>{{ name.toUpperCase() }}</span> <!-- 调用方法 -->
```

#### 属性绑定

```html
<!-- 绑定 HTML 属性 -->
<img :src="avatarUrl" :alt="name" />
<a :href="linkUrl">点击跳转</a>

<!-- 绑定 class（动态添加/移除类名） -->
<div :class="{ active: isActive, disabled: isDisabled }"></div>
<div :class="['basic', { active: isActive }]"></div>

<!-- 绑定 style（动态样式） -->
<div :style="{ color: textColor, fontSize: '16px' }"></div>
```

#### 事件绑定

```html
<!-- 点击事件 -->
<button @click="handleClick">点击</button>

<!-- 双击事件 -->
<button @dblclick="handleDoubleClick">双击</button>

<!-- 输入事件（输入框内容变化时触发） -->
<input @input="handleInput" />

<!-- 带参数 -->
<button @click="handleDelete(id)">删除 {{ id }}</button>

<!-- 阻止默认行为（如表单提交） -->
<form @submit.prevent="handleSubmit">...</form>
```

#### 条件渲染

```html
<!-- v-if：条件满足才渲染，不满足时 DOM 中不存在 -->
<div v-if="show">显示内容</div>

<!-- v-if / v-else -->
<div v-if="isLogin">欢迎回来，{{ name }}</div>
<div v-else>请登录</div>

<!-- v-show：始终渲染，通过 display 控制显示隐藏（适合频繁切换） -->
<div v-show="show">始终存在于 DOM 中</div>
```

#### 列表渲染

```html
<!-- v-for：遍历数组 -->
<ul>
  <li v-for="item in list" :key="item.id">
    {{ item.name }} - {{ item.price }}
  </li>
</ul>

<!-- 带索引 -->
<ul>
  <li v-for="(item, index) in list" :key="item.id">
    {{ index + 1 }}. {{ item.name }}
  </li>
</ul>

<!-- 遍历对象 -->
<div v-for="(value, key) in user" :key="key">
  {{ key }}: {{ value }}
</div>
```

**注意**：`:key` 属性必须有，且值要唯一，帮助 Vue 识别列表项。

### 2.4 生命周期

```javascript
import { onMounted, onUnmounted, onUpdated } from 'vue'

// 组件挂载后执行（页面加载完成）
onMounted(() => {
  console.log('页面加载完成')
  // 通常在这里发起 API 请求，获取数据
})

// 组件更新后执行（数据变化导致视图更新后）
onUpdated(() => {
  console.log('页面更新了')
})

// 组件卸载前执行（页面跳转前）
onUnmounted(() => {
  console.log('页面即将离开')
  // 通常在这里清理定时器、取消请求等
})
```

### 2.5 模板引用

```html
<template>
  <input ref="inputRef" type="text" />
  <button @click="focusInput">聚焦输入框</button>
</template>

<script setup>
import { ref } from 'vue'

// 创建引用
const inputRef = ref(null)

function focusInput() {
  // 通过引用访问 DOM 元素
  inputRef.value?.focus()
}
</script>
```

## 第三章：路由系统详解

### 3.1 路由是什么？

路由就是 URL 和页面组件的映射关系：
- 访问 `/login` → 显示登录页面
- 访问 `/dashboard` → 显示仪表盘页面
- 访问 `/products` → 显示商品管理页面

### 3.2 路由配置

查看 [router/index.js](file:///e:/me/cyi-app/web/admin/src/router/index.js)：

```javascript
const routes = [
  // 登录页（不需要登录就能访问）
  {
    path: '/login',           // URL 路径
    name: 'Login',            // 路由名称（用于编程式导航）
    component: () => import('../views/login/LoginView.vue'),  // 对应组件
    meta: { title: '管理员登录' }  // 元数据（页面标题）
  },
  // 管理后台布局（嵌套路由，需要登录）
  {
    path: '/',
    component: () => import('../layouts/AdminLayout.vue'),
    redirect: '/dashboard',   // 默认跳转到仪表盘
    children: [               // 子路由（在 AdminLayout 内部显示）
      {
        path: 'dashboard',
        name: 'Dashboard',
        component: () => import('../views/dashboard/DashboardView.vue'),
        meta: { title: '仪表盘' }
      },
      {
        path: 'products',
        name: 'Products',
        component: () => import('../views/products/ProductListView.vue'),
        meta: { title: '商品管理' }
      }
    ]
  }
]
```

### 3.3 路由导航方式

#### 模板中导航（声明式）

```html
<!-- 普通跳转 -->
<router-link to="/dashboard">仪表盘</router-link>

<!-- 带参数 -->
<router-link :to="`/products/edit/${id}`">编辑商品</router-link>

<!-- 命名路由（推荐，更清晰） -->
<router-link :to="{ name: 'Dashboard' }">仪表盘</router-link>
<router-link :to="{ name: 'ProductEdit', params: { id: row.id } }">编辑</router-link>
```

#### 代码中导航（编程式）

```javascript
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()  // 用于跳转
const route = useRoute()    // 用于获取路由信息

// 跳转到仪表盘
router.push('/dashboard')

// 命名路由跳转（推荐）
router.push({ name: 'Dashboard' })

// 带参数跳转
router.push(`/products/edit/${id}`)
router.push({ name: 'ProductEdit', params: { id: id } })

// 返回上一页
router.back()

// 获取路由参数（如编辑页面获取商品 ID）
const productId = route.params.id
```

### 3.4 路由守卫

路由守卫在页面跳转前后执行，用于控制访问权限：

```javascript
router.beforeEach((to, from, next) => {
  // 设置页面标题
  document.title = to.meta.title ? `${to.meta.title} - 悦选商城` : '悦选商城'
  
  const store = useAppStore()
  
  // 未登录访问受保护页面 → 跳转登录页
  if (to.name !== 'Login' && !store.isLoggedIn) {
    next({ name: 'Login' })
  } 
  // 已登录访问登录页 → 跳转仪表盘
  else if (to.name === 'Login' && store.isLoggedIn) {
    next({ name: 'Dashboard' })
  } 
  // 正常跳转
  else {
    next()
  }
})
```

**参数说明**：
- `to`：即将前往的路由
- `from`：当前所在的路由
- `next`：决定是否放行（调用 `next()` 放行，`next({ name: 'Login' })` 重定向）

## 第四章：状态管理入门

### 4.1 什么是状态管理？

状态管理用于管理全局共享的数据，比如：
- 用户登录状态（是否已登录）
- 用户信息（姓名、头像、角色）
- 侧边栏折叠状态

这些数据需要在多个组件中共享，使用 Pinia 来管理。

### 4.2 Pinia Store 结构

查看 [store/app.js](file:///e:/me/cyi-app/web/admin/src/store/app.js)：

```javascript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

// 创建 store，第一个参数是唯一 ID（'app'）
export const useAppStore = defineStore('app', () => {
  // 1. 状态（响应式数据）
  const adminInfo = ref(null)  // 管理员信息
  const sidebarCollapsed = ref(false)  // 侧边栏折叠状态
  
  // 2. 计算属性（根据状态计算得出）
  const isLoggedIn = computed(() => {
    return !!localStorage.getItem('admin_token') && !!adminInfo.value
  })
  
  // 3. 方法（修改状态）
  function login(userInfo) {
    adminInfo.value = {
      name: userInfo.name || '管理员',
      avatar: userInfo.avatar || '管'
    }
    if (userInfo.token) {
      localStorage.setItem('admin_token', userInfo.token)
    }
    localStorage.setItem('admin_info', JSON.stringify(adminInfo.value))
  }
  
  function logout() {
    adminInfo.value = null
    localStorage.removeItem('admin_token')
    localStorage.removeItem('admin_info')
  }
  
  // 4. 暴露给外部使用
  return {
    adminInfo,
    sidebarCollapsed,
    isLoggedIn,
    login,
    logout,
    toggleSidebar() { sidebarCollapsed.value = !sidebarCollapsed.value }
  }
})
```

### 4.3 使用 Store

在任何组件中：

```javascript
import { useAppStore } from '../store/app'

const store = useAppStore()

// 获取状态
console.log(store.isLoggedIn)      // 是否登录（true/false）
console.log(store.adminInfo.name)  // 管理员姓名
console.log(store.sidebarCollapsed) // 侧边栏是否折叠

// 修改状态（通过方法）
store.login({ token: 'xxx', name: '管理员', avatar: '张' })
store.logout()
store.toggleSidebar()
```

### 4.4 localStorage 的作用

`localStorage` 是浏览器提供的本地存储，特点：
- 数据永久保存（除非手动删除）
- 页面刷新后数据仍然存在
- 用于持久化登录状态

```javascript
// 保存数据
localStorage.setItem('key', 'value')
localStorage.setItem('user', JSON.stringify({ name: '张三' }))

// 获取数据
const value = localStorage.getItem('key')
const user = JSON.parse(localStorage.getItem('user'))

// 删除数据
localStorage.removeItem('key')
```

**为什么需要 localStorage？**
- 如果不使用 localStorage，页面刷新后登录状态会丢失
- 用户需要重新登录，体验不好
- localStorage 让登录状态持久化

### 5.2 请求封装

项目对 Axios 进行了封装，添加了自动 Token 和统一错误处理。

查看 [api/index.js](file:///e:/me/cyi-app/web/admin/src/api/index.js)：

```javascript
import axios from 'axios'

// 创建 Axios 实例
const request = axios.create({
  timeout: 15000  // 超时时间 15 秒
})

// 请求拦截器 - 自动添加 Token
request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('admin_token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  }
)

// 响应拦截器 - 统一错误处理
request.interceptors.response.use(
  response => {
    const data = response.data
    // 业务错误处理（后端返回 code !== 0 表示业务异常）
    if (data.code !== 0 && data.code !== undefined) {
      ElMessage.error(data.message || '请求失败')
      return Promise.reject(new Error(data.message))
    }
    return data
  },
  error => {
    if (error.response?.status === 401) {
      // Token 失效，跳转登录页
      ElMessage.error('登录已过期')
      store.logout()
      setTimeout(() => router.push('/login'), 1500)
    }
    return Promise.reject(error)
  }
)

export default request
```

### 9.2 常见错误及解决

#### 错误 1：Cannot read properties of undefined

```
TypeError: Cannot read properties of undefined (reading 'name')
```

**原因**：访问了一个 undefined 对象的属性

**解决**：

```javascript
// 错误写法
console.log(data.admin.name)  // data.admin 可能为 undefined

// 正确写法 - 使用可选链
console.log(data?.admin?.name)

// 或添加判断
if (data && data.admin) {
  console.log(data.admin.name)
}
```

#### 错误 2：401 Unauthorized

```
Error: 401 Unauthorized
```

**原因**：请求没有携带 Token 或 Token 已过期

**解决**：
- 检查 localStorage 中是否有 `admin_token`
- 检查 Network 面板中请求头是否有 `Authorization: Bearer xxx`
- 重新登录获取新 Token

#### 错误 3：Form validation failed

```
Form validation failed
```

**原因**：表单验证未通过

**解决**：检查表单规则和输入值，确保所有必填项都已填写

#### 错误 4：Component is not defined

```
ReferenceError: Component is not defined
```

**原因**：使用了未导入的组件或图标

**解决**：检查 import 语句，确保所有组件都已正确导入

#### 错误 5：Module not found

```
Error: Cannot find module './api/auth'
```

**原因**：文件路径错误

**解决**：检查文件路径，确保文件存在
