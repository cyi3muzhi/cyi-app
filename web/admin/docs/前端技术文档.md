## 1. 项目概览

**悦选商城管理后台** 是一个基于 Vue 3 的单页应用（SPA），为商城管理员提供商品管理、订单管理、用户管理、优惠券管理等功能。

### 项目特点

- **前后端分离**：前端通过 HTTP API 与后端微服务通信
- **权限控制**：基于 JWT 的认证机制，路由守卫保护页面访问
- **响应式设计**：适配桌面端、平板和移动端，支持 4K 大屏
- **组件化开发**：采用 Vue 3 Composition API，代码结构清晰
- **Mock 数据**：提供完整的模拟数据，便于开发调试

#### 路由守卫

```javascript
router.beforeEach((to, from, next) => {
  // 设置页面标题（从路由 meta 中读取）
  document.title = to.meta.title ? `${to.meta.title} - 悦选商城管理后台` : '悦选商城管理后台'

  const store = useAppStore()
  
  // 未登录且访问非登录页 → 跳转到登录页
  if (to.name !== 'Login' && !store.isLoggedIn) {
    next({ name: 'Login' })
  }
  // 已登录且访问登录页 → 跳转到仪表盘
  else if (to.name === 'Login' && store.isLoggedIn) {
    next({ name: 'Dashboard' })
  }
  // 正常放行
  else {
    next()
  }
})
```

**关键点**:
- `router.beforeEach()` 全局前置守卫，在每个路由跳转前执行
- `useAppStore()` 获取状态管理，判断用户登录状态
- `meta` 字段用于存储页面标题等元信息
- 动态导入组件 `() => import(...)` 实现代码分割，按需加载

### 4.3 状态管理

**文件**: `src/store/app.js`

使用 Pinia 的 Composition API 风格定义状态：

```javascript
export const useAppStore = defineStore('app', () => {
  // 响应式状态
  const sidebarCollapsed = ref(false)  // 侧边栏折叠状态
  const activeMenu = ref('')           // 当前高亮菜单
  const adminInfo = ref(loadAdminInfo())  // 管理员信息（从 localStorage 读取）
  const notificationCount = ref(3)     // 通知数量

  // 计算属性
  const sidebarWidth = computed(() => sidebarCollapsed.value ? '64px' : '240px')
  
  const isLoggedIn = computed(() => {
    return !!localStorage.getItem('admin_token') && !!adminInfo.value
  })

  // 方法
  function loadAdminInfo() {
    try {
      const saved = localStorage.getItem('admin_info')
      if (saved) {
        return JSON.parse(saved)
      }
    } catch {
      // ignore
    }
    return null
  }

  function login(userInfo) {
    adminInfo.value = {
      name: userInfo.name || '管理员',
      avatar: userInfo.avatar || '管',
      role: userInfo.role || '超级管理员',
      email: userInfo.email || '',
      username: userInfo.username || ''
    }
    if (userInfo.token) {
      localStorage.setItem('admin_token', userInfo.token)
    }
    localStorage.setItem('admin_info', JSON.stringify(adminInfo.value))
  }

  function logout() {
    adminInfo.value = null
    localStorage.removeItem('admin_token')
    localStorage.removeItem('admin_info')
  }

  return {
    sidebarCollapsed,
    activeMenu,
    adminInfo,
    notificationCount,
    sidebarWidth,
    isLoggedIn,
    toggleSidebar() { sidebarCollapsed.value = !sidebarCollapsed.value },
    login,
    logout
  }
})
```

**关键点**:
- `defineStore()` 定义一个 store，第一个参数是 store 名称（必须唯一）
- `ref()` 创建响应式变量，`reactive()` 创建响应式对象
- `computed()` 创建计算属性（依赖其他状态自动更新，有缓存）
- 状态持久化：使用 `localStorage` 保存登录信息，刷新页面后仍保持登录状态
- `loadAdminInfo()` 在初始化时从 localStorage 恢复数据

### 4.4 API 请求封装

**文件**: `src/api/index.js`

#### 创建 Axios 实例

```javascript
const request = axios.create({
  baseURL: '',           // 基础 URL（通过 Vite 代理配置，不需要填写）
  timeout: 15000         // 请求超时时间（15秒）
})
```

#### 请求拦截器

在发送请求前自动添加 Token：

```javascript
request.interceptors.request.use(
  config => {
    const token = localStorage.getItem('admin_token')
    if (token) {
      // 按后端要求的格式添加到 Authorization 头
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  error => Promise.reject(error)
)
```

#### 响应拦截器

统一处理响应和错误：

```javascript
request.interceptors.response.use(
  response => {
    const data = response.data
    // 业务错误处理（后端返回 code !== 0 表示业务异常）
    if (data.code !== 0 && data.code !== undefined) {
      ElMessage.error(data.message || '请求失败')
      return Promise.reject(new Error(data.message))
    }
    return data
  },
  error => {
    if (error.response) {
      const { status } = error.response
      if (status === 401) {
        // Token 失效：清除登录状态，显示提示，延迟 1.5 秒后跳转登录页
        const store = useAppStore()
        const message = error.response.data?.message || '登录已过期，请重新登录'
        ElMessage.error(message)
        store.logout()
        setTimeout(() => {
          router.push('/login')
        }, 1500)
      } else if (status === 403) {
        ElMessage.error('没有权限执行此操作')
      } else {
        ElMessage.error(error.response.data?.message || '服务器错误')
      }
    } else {
      ElMessage.error('网络连接失败，请检查网络')
    }
    return Promise.reject(error)
  }
)
```

**关键点**:
- 请求拦截器自动在请求头中添加 `Authorization: Bearer {token}`
- 响应拦截器统一处理 401（未授权）、403（无权限）等 HTTP 状态码
- 401 时先显示错误消息，清除登录状态，延迟跳转登录页（提升用户体验）
- 业务错误（code !== 0）也会弹出错误提示

### 4.4.1 认证 API

**文件**: `src/api/auth.js`

```javascript
import request from './index'

// 管理员登录
export function login(username, password) {
  return request.post('/admin/v1/auth/login', { username, password })
}

// 管理员登出（Token 通过拦截器自动添加）
export function logout() {
  return request.post('/admin/v1/auth/logout')
}

// 获取当前管理员信息
export function getAdminInfo() {
  return request.get('/admin/v1/auth/info')
}

// 更换头像（上传 Base64 图片）
export function changeAvatar(avatarBase64) {
  return request.post('/admin/v1/auth/avatar', { avatar_base64: avatarBase64 })
}
```

**关键点**:
- API 函数统一返回 Promise，可以使用 `async/await` 调用
- 参数使用对象形式传递，与后端接口字段对应
- 头像上传采用 Base64 编码方式，方便前端处理

## 5. 开发规范

### 5.1 组件命名

- **文件命名**：使用 PascalCase（大驼峰），如 `ProductListView.vue`
- **组件名称**：语义化命名，描述组件功能
- **目录结构**：同类页面放在同一文件夹下，如 `views/products/`

### 5.2 API 调用

- 统一通过 `src/api/index.js` 封装的 `request` 对象调用
- 认证相关 API 放在 `src/api/auth.js`
- Mock 数据放在 `src/api/mock.js`
- API 函数使用 `export function` 导出，方便按需导入

### 5.3 状态管理

- 全局状态放在 `store/app.js`
- 使用 `useAppStore()` 获取状态
- 不要直接修改 localStorage，通过 store 的 `login()` 和 `logout()` 方法操作
- 状态命名清晰，使用 `camelCase`

### 5.4 路由跳转

- 使用 `router.push()` 进行页面跳转
- 优先使用命名路由 `router.push({ name: 'Dashboard' })`
- 登录成功后使用 `window.location.href` 强制刷新（避免路由守卫时序问题）

### 5.5 样式规范

- 全局样式变量定义在 `src/assets/styles/variables.css`
- 全局通用样式放在 `src/assets/styles/global.css`
- 组件内样式使用 `<style scoped>` 隔离（避免样式污染）
- 使用 CSS 变量 `var(--shop-primary)` 保持主题一致
- 响应式使用媒体查询：1024px（平板）、768px（手机）、480px（小屏）

### 5.6 代码风格

- 使用 ES6+ 语法（箭头函数、解构、模板字符串）
- 组件中使用 `<script setup>` 语法（Composition API）
- 变量声明使用 `const`（优先）或 `let`，不使用 `var`
- 函数命名使用 `camelCase`
- 添加适当的注释，说明函数用途和参数

### 6.1 如何添加新页面？

import { ref } from 'vue'
const list = ref([])

  console.log('添加会员')

### 6.2 如何调用后端 API？

1. 在 `src/api/` 目录下创建新文件或在现有文件中添加接口函数
2. 在组件中导入并使用 `async/await` 调用
3. 示例：

```javascript
import { getAdminInfo } from '../api/auth'

async function loadData() {
  try {
    const res = await getAdminInfo()
    console.log(res.admin)
  } catch (error) {
    console.error('获取信息失败:', error)
  }
}
```

### 6.3 如何处理登录状态？

- 通过 `useAppStore().isLoggedIn` 判断是否登录
- 通过 `store.login(userInfo)` 保存登录信息（自动存储到 localStorage）
- 通过 `store.logout()` 清除登录信息（自动删除 localStorage）
- 页面刷新后自动从 localStorage 恢复登录状态

### 6.4 如何调试 API 请求？

- 使用浏览器开发者工具的 **Network** 面板查看请求
- 检查请求 URL、方法、参数是否正确
- 检查请求头中是否包含 `Authorization: Bearer {token}`
- 查看响应状态码和返回数据
- 在拦截器中添加 `console.log` 调试

### 6.5 响应式布局如何适配？

- 使用 Element Plus 的栅格系统（`el-row`、`el-col`）
- 使用 CSS Media Query 适配不同屏幕尺寸
- 参考现有页面的响应式实现（如 DashboardView.vue）
- 小屏时表格列可能需要横向滚动

### 6.6 如何上传图片？

项目当前采用 **Base64 编码上传**方案：

1. 使用 `FileReader` 将图片转为 Base64
2. 截取 Base64 数据部分（去掉 `data:image/png;base64,` 前缀）
3. 调用 `changeAvatar(base64Data)` 上传
4. 后端接收后解码，上传到 OSS，返回永久 URL

### 6.7 Token 失效怎么办？

- 后端返回 401 时，响应拦截器会自动处理
- 清除 localStorage 中的 token 和用户信息
- 显示错误提示消息（如"登录已过期，请重新登录"）
- 延迟 1.5 秒后跳转到登录页面

### 6.8 如何使用 Vue DevTools 调试？

1. **安装插件**：在 Chrome/Edge 浏览器扩展商店搜索 "Vue DevTools" 安装
2. **打开开发者工具**：按 F12，切换到 "Vue" 标签
3. **功能介绍**：

   - **组件状态**：查看和修改组件的响应式数据
   - **路由**：查看当前路由和参数
   - **时间线**：记录组件更新过程

### 6.9 如何格式化代码？

项目使用 VS Code 的 ESLint 和 Prettier 插件自动格式化代码：

1. **安装插件**：在 VS Code 扩展中搜索安装 "ESLint" 和 "Prettier"
2. **设置自动格式化**：

### 6.10 如何处理跨域问题？

项目使用 Vite 代理解决跨域问题，配置在 `vite.config.js`：

```javascript
server: {
  proxy: {
    '/admin/v1': {
      target: 'http://localhost:28000',
      changeOrigin: true  // 允许跨域
    }
  }
}
```

**工作原理**：
- 前端请求 `/admin/v1/auth/login`
- Vite 将请求转发到 `http://localhost:28000/admin/v1/auth/login`
- 浏览器认为请求是同源的（都是 localhost:3000）
- 后端收到请求后正常处理并返回
